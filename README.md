# KickBlast Judo Management System 🥋

KickBlast Judo is a comprehensive desktop application built to streamline the daily operations of a Judo club or martial arts academy. Built using C# and Windows Forms, it provides an intuitive interface for administrators to track athletes, manage memberships, and handle financial records.

## 🌟 Features

*   **User Authentication:** Secure login system for administrators (`Login.cs`).
*   **Admin Dashboard:** Centralized hub for managing club activities (`AdminForm.cs`, `MainForm.cs`).
*   **Athlete Management:** Register new students, view detailed profiles, and update athlete information (`Athletes.cs`, `AthleteDetails.cs`).
*   **Fee Tracking:** Keep track of membership payments, overdue balances, and financial records (`FeeRecords.cs`).
*   **Database Integration:** Structured SQL database for reliable data storage (`Script.sql`).

## 💻 Technologies Used

*   **Language:** C#
*   **Framework:** .NET Framework (Windows Forms / WinForms)
*   **Database:** SQL (SQL Server/LocalDB)
*   **IDE:** Visual Studio
